# Stock Intelligence AI — Android app

Kotlin · Jetpack Compose · Material 3 · MVVM/Clean · Hilt · Retrofit.
Dark-only premium theme. Talks to the FastAPI backend in `../backend`.

## What's built (this milestone)

- 5-tab bottom nav: Home · Markets · Discover · Portfolio · AI Chat.
- **Home** — global/India sentiment tiles, NIFTY/BANKNIFTY cards, and a live
  "Top AI signals" list that calls `GET /stock/{symbol}` for a default watchlist.
- **Stock detail** — full recommendation card (label, confidence bar, entry/target/
  stop-loss/R:R), "Why this signal?" reasons, a technicals grid (RSI, trend, VWAP,
  EMAs, support/resistance, MACD), data-freshness line, and the disclaimer. Calls
  `GET /stock/{symbol}/analysis`.
- Markets / Discover / Portfolio / AI Chat are tasteful placeholders that name what
  lands next (their backend endpoints are described inline).
- Networking via Retrofit/OkHttp/Hilt; DTOs match the backend JSON exactly; screen
  state via `StateFlow` + `UiState`.

## Run it

1. Start the backend (`cd ../backend && docker compose up`).
2. Open the `android/` folder in **Android Studio** (Ladybug or newer).
3. Let Gradle sync. The app targets the emulator by default — `BASE_URL` is
   `http://10.0.2.2:8000/` (the emulator's alias for your host machine).
   - On a physical device, change `BASE_URL` in `app/build.gradle.kts` to your
     machine's LAN IP and add that host to `res/xml/network_security_config.xml`.
4. Run the `app` configuration on an emulator/device.

Even with the backend on the **mock feed** (no vendor keys yet), Home populates and
every stock opens a full analysis — so you can click through the whole flow today.

## Build APK / AAB (you run these — signing needs your keystore)

```bash
cd android
./gradlew assembleDebug        # debug APK -> app/build/outputs/apk/debug/
./gradlew assembleRelease      # release APK (configure signing first)
./gradlew bundleRelease        # AAB for Play -> app/build/outputs/bundle/release/
```

Add a signing config to `app/build.gradle.kts` (`signingConfigs { create("release") { ... } }`)
pointing at your keystore before `assembleRelease`/`bundleRelease`. I can wire a
`keystore.properties`-based signing setup for you in the build milestone.

## Two things to add before first run

- **Gradle wrapper binary.** `gradle/wrapper/gradle-wrapper.properties` is included, but
  the `gradlew`/`gradlew.bat` scripts and `gradle-wrapper.jar` are generated by Android
  Studio on first open (or run `gradle wrapper` if you have a local Gradle). This is
  normal — they're binaries/scripts, not source.
- **Launcher icon.** No custom mipmap is bundled, so the system default is used. Add one
  via Studio's Image Asset wizard (or drop `mipmap-*/ic_launcher`) and reference it with
  `android:icon` in the manifest.
